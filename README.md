Atividade Prática — Página Interativa com HTML, CSS e JavaScript
Tema da atividade
Cada aluno deverá desenvolver uma página web com o tema:
“Guia Digital de Hábitos Saudáveis para Estudantes”
A ideia é criar uma página simples, bonita e interativa que apresente dicas para melhorar a rotina dos estudantes, abordando temas como alimentação, sono, estudo, atividade física, uso da tecnologia e organização do tempo.
Objetivo
Desenvolver uma página utilizando HTML, CSS e JavaScript, aplicando conceitos de estruturação, estilização e interatividade.
Ao final da atividade, o estudante deverá demonstrar que consegue criar uma página organizada, visualmente agradável e com pelo menos uma funcionalidade usando JavaScript.

Situação-problema
Muitos estudantes têm dificuldade para organizar sua rotina de estudos, cuidar da saúde, dormir bem e equilibrar o uso da tecnologia.
Pensando nisso, você deverá criar uma página chamada:
Vida de Estudante: Guia de Hábitos Saudáveis
Essa página deverá orientar outros alunos com dicas simples e práticas para melhorar a qualidade de vida durante os estudos.

Requisitos da página
A página deverá conter:
1. Cabeçalho
O cabeçalho deve apresentar:
nome do projeto;
menu com pelo menos 3 links internos, como:
Início
Dicas
Teste de Hábitos

2. Seção inicial
Crie uma área de abertura com:
título principal;
imagem ou ilustração relacionada ao tema;
pequeno texto explicando a importância de manter hábitos saudáveis.
Exemplo de título:
Cuide da sua rotina, melhore seus estudos

3. Cards de dicas
A página deverá ter pelo menos 4 cards, cada um com uma dica diferente.
Sugestões:
Sono: dormir bem melhora a concentração.
Alimentação: refeições equilibradas ajudam na energia diária.
Estudo: pequenas pausas ajudam no aprendizado.
Tecnologia: evite excesso de tela antes de dormir.
Atividade física: movimentar o corpo ajuda na disposição.
Cada card deve conter:
título;
ícone ou imagem;
texto curto;
efeito visual com CSS ao passar o mouse.

4. Área com JavaScript
A página deverá ter uma funcionalidade feita com JavaScript.
Escolha uma das opções abaixo:
Opção 1 — Teste de hábitos
Criar um pequeno formulário com perguntas como:
Você dorme pelo menos 7 horas por noite?
Você faz pausas durante os estudos?
Você pratica alguma atividade física?
Você evita usar celular antes de dormir?
Ao clicar em um botão, o JavaScript deverá mostrar uma mensagem final, como:
Parabéns! Você está cuidando bem da sua rotina.
ou
Atenção! Você pode melhorar alguns hábitos.

Opção 2 — Gerador de dica aleatória
Criar um botão chamado:
Receber dica saudável
Quando o usuário clicar, o JavaScript deverá mostrar uma dica aleatória na tela.
Exemplo:
"Beba água durante o dia."
"Organize seus horários de estudo."
"Durma bem antes de uma prova."
"Faça pausas curtas entre as atividades."

Opção 3 — Calculadora de rotina
Criar campos para o usuário informar:
quantas horas dorme por noite;
quantas horas estuda por dia;
quantas horas usa celular por dia.
Depois, o JavaScript deverá mostrar uma mensagem de orientação.

Tecnologias obrigatórias
O projeto deverá conter os seguintes arquivos:
index.html
style.css
script.js
O aluno deverá utilizar:
HTML para estruturar o conteúdo;
CSS para estilizar a página;
JavaScript para criar a interação.

Requisitos técnicos
O projeto deve apresentar:
estrutura HTML organizada;
uso correto de títulos, parágrafos, imagens, botões e formulários;
arquivo CSS separado;
arquivo JavaScript separado;
layout com cores agradáveis;
cards organizados;
pelo menos uma interação com JavaScript;
comentários simples no código;
responsividade básica para celular.

Entrega
O aluno deverá entregar:
link do repositório no GitHub;
print da página funcionando;
arquivos index.html, style.css e script.js;
pequena explicação sobre o que o JavaScript faz no projeto.

Critérios de avaliação
A atividade será avaliada considerando:
organização do código;
criatividade da página;
uso correto de HTML;
estilização com CSS;
funcionalidade com JavaScript;
clareza das informações;
responsividade;
entrega completa dos arquivos;
funcionamento da página.

Desafio extra
Os alunos que desejarem poderão acrescentar:
modo claro e escuro;
animações com CSS;
mais perguntas no teste de hábitos;
barra de progresso;
salvamento de resposta usando localStorage;
botão para voltar ao topo da página.
